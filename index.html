Abstract

Collecting real-robot demonstrations across varied layouts and visual conditions is costly. Simulation can broaden this coverage, but discrepancies in geometry, contact dynamics, and appearance often hinder sim-to-real policy transfer. We introduce RoboExpand, an agentic Real2Sim2Real data engine that expands a single real-robot demonstration into diverse action trajectories and visual observations for policy learning. A reconstruction agent first replays the recorded actions and uses discrepancies in contact and object motion to refine the scene’s geometry and physics. A trajectory generalization agent then adapts the demonstrated motion to new object layouts by planning paths that account for the new object positions. For each successful trajectory, the engine’s learned multi-view transfer model finally generates synchronized videos under different visual conditions, preserving alignment with the trajectory’s actions and states. Across four tasks on three real robot platforms, with 80 demonstrations per task, policies trained on RoboExpand-generated data achieved 72.5% average success rate, up from 40.0% with raw simulator renderings and close to the 75.0% achieved with real demonstrations. In two additional Astribot task generalization experiments, policies trained on synthetic data covering the five tested visual conditions achieved 68.0% average success rate, compared with 39.0% for policies trained on real demonstrations from the default scene.

Method

Reconstruction Agent

Starting from one demonstration and the robot’s URDF, the agent calibrates the cameras and reconstructs object geometry, materials, and scene layout. It then adds collision models and physical parameters, replays the recorded actions, and compares simulated contact and object motion with the demonstration. Discrepancies guide targeted revisions until the scene reproduces the task’s key interactions.

Generalization Agent

The agent divides the reference motion into stages such as grasping, transport, and release, then samples new object layouts. It adapts object-relative targets, reuses motion segments that remain valid, and invokes cuRobo to replan affected segments. Successful simulation rollouts provide synchronized RGB-D observations together with the corresponding robot actions and scene states.

Multi-view Video Transfer

Simulated depth preserves the trajectory’s motion and scene structure, while per-camera reference images and a shared caption control appearance. Cross-view residual blocks exchange features between the head and wrist cameras to generate consistent observations. History-conditioned continuation extends generation to longer rollouts, retaining alignment with the original simulation actions and states.
